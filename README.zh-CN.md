# WatchVid4U · 帮你看视频

[English](README.md) | **简体中文**

**不下载视频、不依赖字幕，像你一样把视频“看”一遍**，得到可保存的中文逐字稿与学习笔记。Chrome 扩展（Manifest V3）。

> **界面语言**：支持简体中文和英文，可在设置页左侧栏顶部的“🌐 中文 / English”切换（默认跟随浏览器语言）。逐字稿与笔记默认面向中文输出。

## 为什么做这个

市面上的视频总结工具，大致有三种获取内容的方式，各有短板：

| 方式 | 短板 |
|---|---|
| 读取视频字幕 | 遇到没有字幕的视频就无能为力 |
| 用 yt-dlp 等工具下载音频再转写 | 容易被视频网站的反下载机制拦截，需要经常更新下载工具和 Cookie 才能继续用 |
| OCR 识别画面里的字幕 | 算力消耗大；各视频的字幕样式不同，适用面窄 |

WatchVid4U 换了一条路：**字幕能用就用字幕；不能用，就在浏览器里真实播放视频，同时录下标签页的声音再转写。** 视频是真的在播放，声音是录制的而不是下载的，对网站来说这和你本人在看没有区别，所以不会触发反下载拦截。代价是速度：一个视频要按正常时长播完才能拿到完整录音。

**核心链路足够稳定**：“录制标签页声音 → 语音转写 → 大模型总结”这条主线只依赖浏览器的标准能力和通用的 API 接口，不依赖任何视频网站的接口，网站改版也不需要跟着修改。会随网站改版而变化的部分（字幕接口、广告识别等）被有意控制在最小范围：字幕获取目前只做了 B站。

**适用范围**：支持主流免费视频网站（已针对 B站、YouTube、抖音做了适配，其他能正常播放出声音的网页也可以录制），但不保证所有网站都能录制，例如受 DRM 保护的付费流媒体内容，浏览器可能不允许录制。

**一次点击**：B站有字幕就直接保存完整字幕为逐字稿；没有可用字幕（或在 YouTube、抖音、普通网页）就在**同一任务中自动录音**，正文播完时**自动暂停网页、阻止自动下一条/循环、结束录音**，再调用你配置的转写服务得到逐字稿；可选再用独立的大模型生成笔记。关闭弹窗、切换标签页都不影响任务。

## 安装

1. 从 GitHub 的 Releases 页面下载 `WatchVid4U-<版本>.zip` 并解压（或克隆仓库后直接使用源码目录 `extension/`）。
2. 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的目录（包含 `manifest.json` 的那一层）。
4. 建议把扩展固定到工具栏。首次安装会自动打开设置页。

要求：Chrome / Edge 等 Chromium 浏览器 116 及以上。

**界面尺寸自适应**：界面按系统自动适配，而不是整体放大或缩小——

- **平台配置**：Windows / Linux 的逻辑像素比 macOS 大，原生界面更紧凑，所以用更小的基准比例和更平缓的字号阶梯（小字基本保持可读，标题收得更多）。
- **字重**：微软雅黑等中文字体没有“中粗”，`600` 会被渲染成整套粗体，因此正文、按钮和标签改用常规字重，只有标题加粗。
- **字形校正**：运行时测量系统实际使用的中文字体的字面大小（雅黑的字面比苹方大），按苹方归一。
- **手动微调**：设置 →「存储与外观」→「界面比例」（80%–125%），实时预览；下方会显示检测到的系统、字形校正和实际比例。作用于弹窗、材料页、设置页和网页浮窗；浏览器自身的缩放与字号设置仍然生效。

## 首次配置

| 你想要 | 需要配置 |
|---|---|
| B站有字幕的视频 → 逐字稿 | **无需配置** |
| 录音转写（无字幕 B站、YouTube、抖音、普通网页） | 设置 →「语音转写」 |
| 学习笔记（精简 / 详细 / 纪要） | 设置 →「笔记模型」 |

**语音转写（云端，推荐）**：任何兼容 OpenAI `/audio/transcriptions` 的同步转写服务。

1. 点击示例按钮（如 Groq：`https://api.groq.com/openai/v1`，模型 `whisper-large-v3`）或自行填写地址与模型。
2. 粘贴你自己的 API Key（插件不内置任何共享 Key，也不保证任何服务长期免费）。
3. 阅读“用途与授权”中列出的接收方、发送内容和可能费用，点击「保存并授权」→ 确认 → 允许浏览器访问该地址。
4. 可点「测试连接」：只发送 1.5 秒的固定测试音，不使用你的录音。

**笔记模型**：任何非流式 Chat Completions 服务。地址可填 `https://host/v1`、带结尾斜杠或完整的 `…/chat/completions`；界面会显示最终请求地址供核对（MiMo、DeepSeek、OpenAI 等示例仅供参考，模型名以服务商文档为准）。

**Key 存储**：默认勾选“在本机记住 Key”，Key 以**未加密**形式存于扩展自己的本机数据中（网页和内容脚本读不到），重启浏览器后无需重填。取消勾选则只保存在本次浏览器会话（关闭浏览器即清除）。更换服务地址时，旧 Key 会被丢弃，不会被发往新地址。

## 日常使用

**三种入口，同一个流程**（同一任务、同一状态、同样执行 B站字幕优先与自动录音回退）：

- **工具栏弹窗**：「开始录制」（从当前进度）/「从头录制」（从正文开头）。
- **网页浮窗**：B站、YouTube、抖音页面右下角的小方块，可拖动、可隐藏（隐藏不影响任务）。
- **浏览器快捷键**（可在 `chrome://extensions/shortcuts` 修改）：

| 操作 | 默认 |
|---|---|
| 从当前进度开始 | `Alt+Shift+S` |
| 从头开始 | `Alt+Shift+B` |
| 停止并保存 | `Alt+Shift+E` |
| 显示/隐藏浮窗 | `Alt+Shift+F` |

另可在设置中开启**站内单键**呼出浮窗（默认关闭；在输入框、评论区和输入法输入时不会响应）。

**一次任务会自动完成**：识别平台 →（B站）尝试完整字幕 → 成功即保存逐字稿 / 否则自动转为录音 → 定位起点（从头时会回到 0 秒；YouTube 会等广告结束后的正文起点）→ 录音就绪后才开始播放 → 正文自然结束时暂停网页并持续阻止自动续播 → 保存音频 → 自动转写 → （可选）自动生成笔记 → 通知（可选）。

- **视频画面（可选，默认关闭）**：在设置 →「视频画面」中开启后，录制时按设定间隔（默认 30 秒）截图，黑屏和重复画面自动跳过，截图只保存在本机，可在材料页查看。再开启并确认“生成笔记时，把截图发给笔记模型参考”，笔记模型就能结合幻灯片、图表、屏幕操作来理解视频（需要模型支持图片输入）。生成的笔记仍是文字，不会插入图片。
- **可同时录制多个标签页**（默认最多 3 个，可在设置中调整）：在每个标签页分别开始，各自录音、各自在播完后结束；录完的音频依次排队转写。弹窗会列出其他标签页的任务，可直接停止、取消或切换过去。
- 录音默认**静音监听**（你听不到，但录音内容完整）；录制中可随时打开“同时听声音”。
- 视频暂停期间录音同步暂停；缓冲、拖动进度、切到后台不会被误判为结束。
- 「停止并保存」= 手动结束；与正常播完、异常中断分别标记。异常中断的录音**不会自动上传**，可在材料页试听后自行决定。
- 播完后网页保持暂停，**直到你主动点击播放或选择其他视频**；保护只针对本次任务，不修改网站的自动播放设置。

**材料与笔记页**：左侧选择材料（可筛选、全选、批量删除、批量导出文字 JSON），右侧查看：

- **逐字稿**：唯一的“有效逐字稿”（多人且可靠时为匿名说话人分段稿，否则为普通稿），可复制、下载 TXT。
- **笔记**：在“笔记”标签顶部先选“笔记风格”（精简 / 详细 / 纪要，带 ● 的已有笔记），紧挨着的按钮即“生成 / 重新生成该风格笔记”；切换风格只显示已有笔记，不会自动联网；逐字稿更新后会提示旧笔记可能过期。
- **音频与来源**：WAV 试听（真实时长、可拖动）与下载、起止方式、YouTube 广告时段；B站字幕的类型（人工/自动/未知）、语言、分P与原始字幕导出。
- 转写失败时保留已完成的分片，「继续转写」只处理剩余部分；失败不会覆盖已有的完整逐字稿。

## 各平台能力

| 平台 | 字幕 | 录音 | 播完处理 | 说明 |
|---|---|---|---|---|
| B站 普通视频（含分P、`/list/` 播放列表页） | ✅ 自动优先获取完整轨道，核对 BV/分P | ✅ 字幕不可用时自动转入 | 暂停 + 阻止自动连播/推荐 | 番剧、课程页暂不取字幕，直接录音 |
| YouTube 普通观看页 `/watch` | — | ✅ | 暂停 + 取消续播倒计时 + 拦截延迟续播 | 区分前贴/中插广告；从头录制会等正文起点 |
| 抖音视频页 / 信息流 | — | ✅ | 暂停 + 阻止从头循环 | 划到下一条视为换片，任务中断并保留已录部分 |
| 其他有声网页 | — | ✅ | 能找到 `<video>/<audio>` 时自动结束 | 找不到可控制的媒体时需手动“停止并保存” |

YouTube Shorts、iframe 内嵌播放器、DRM 受保护内容不在本轮支持范围内。

## 可选：本地转写服务

不想用云服务、或想区分说话人时使用。可以用本项目自带的后端，也可以用任何兼容 OpenAI `/audio/transcriptions` 接口、运行在本机（`127.0.0.1` / `localhost`）的转写服务。

**自带后端**（详见 [local-backend/README.md](local-backend/README.md)）要点：

- 只监听 `127.0.0.1`，只接受 `chrome-extension://` 来源（可用 `--allow-origin` 限定为你的扩展 ID）。
- 自动选择 mlx-whisper（Apple Silicon，可复用 Hugging Face 缓存中已有的 `mlx-community/whisper-*` 模型）或 faster-whisper；**运行时绝不下载模型**。
- 说话人区分需要本地的 pyannote 模型；不可用或失败时仍返回完整普通逐字稿。
- 设置 → 语音转写 → 选择「本地服务」→ 保存并授权 →「测试转写」。

**其他本地服务**：在「本地服务」中填它的地址（可填 `http://127.0.0.1:端口`、`…/v1` 或完整的 `…/audio/transcriptions`）、它认可的模型名；服务要求时再填 Key（可选）。「测试转写」会发送一段固定测试音走一遍完整请求，通过即可直接使用。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 浮窗点开始后提示“需要你授权录音” | 浏览器规定：只有在你**点击工具栏图标或按浏览器快捷键**启动过扩展的页面，才允许录制标签页声音。点一次工具栏图标，在弹窗中点「授权并继续录音」即可（同一页面之后不再需要）。 |
| B站提示“需要登录才能获取字幕” | 在设置 → B站字幕中开启“允许使用当前浏览器的 B站登录状态”。否则会自动录音转写。 |
| 字幕“不符合采用策略” | 设置里关闭了自动/未知来源字幕或非中文字幕；会自动录音。 |
| 录音提示“持续静音” | 视频未在播放、网页静音或音量为 0。 |
| 提示“浏览器阻止了自动继续播放” | 录音已就绪，在网页上点一下播放即可。 |
| 转写：“服务返回了网页” | 地址多半少了 `/v1` 或填成了网站首页；对照设置中显示的“请求地址”。 |
| 转写：HTTP 413 | 服务商的上传上限比设置值小，在“高级”中调低“单次上传上限”。插件会据此自动分片。 |
| 转写：HTTP 401/403、429 | Key 无效/无权限；或限流、额度不足。 |
| 笔记：“返回了流式响应 / 输出被截断 / 内容为空” | 服务不支持 `stream:false`；或“最大输出 tokens”过小；或模型拒答。旧笔记会保留。 |
| 笔记：“超过最大输入字数” | 插件不会静默截断；在设置 → 笔记模型 → 高级中调大上限。 |
| 任务一直“处理中” | 打开弹窗查看具体环节；可以取消。取消只停止本地等待，服务商可能仍会计费。 |

## 隐私

见 [docs/PRIVACY.md](docs/PRIVACY.md)。简要：没有项目方服务器、代理或统计；材料只存本机；只有你授权的转写/笔记服务会收到数据（转写只收到当前音频与必要参数，笔记只收到当前有效逐字稿与固定提示词；开启“生成笔记时参考截图”时另含少量截图）；不发送标题、网址、账号；不读取 Cookie 值、不下载视频、不绕过任何访问限制。

## 项目结构与开发

```
extension/                 扩展源码（零构建、零第三方运行时依赖，原生 ES Modules）
  manifest.json
  src/background/sw.js     任务状态机（唯一入口汇聚点、锁、标签页生命周期、自动转写/笔记编排）
  src/offscreen/           录音（AudioWorklet → 16 kHz PCM → IndexedDB 分块）与转写/笔记任务执行
  src/content/             页面代理：定位视频、起点、结束判定、播完保护、YouTube 广告状态、B站字幕请求、浮窗
  src/shared/              设置/授权、STT/LLM 客户端、分片、逐字稿合成、提示词、B站字幕、Markdown 安全渲染、数据库
  src/ui/                  弹窗、材料与笔记、设置
local-backend/server.py    可选本地转写服务（标准库 HTTP；推理依赖可选）
tests/                     浏览器内单测、扩展端到端测试、本地后端测试、夹具服务器与媒体
scripts/                   图标生成、打包
docs/                      隐私说明
```



## 验证情况与已知限制

- **已在本机真实执行并通过**：85 项浏览器内单测；132 项扩展端到端检查（含模拟 Windows UA 与 1.5 倍 DPI 的界面检查）（真实 Chrome 155 加载扩展，模拟 B站/YouTube/抖音页面与接口，模拟 STT/LLM 服务）；7 项本地后端协议测试。
- **替身/模拟的部分**：标签页声音来源（`tabCapture` 必须由用户点击工具栏图标授权，自动化无法触发，测试中用同一份测试音频生成的媒体流代替）；三个平台的页面和接口均为本地夹具；STT/LLM 为本地模拟服务；本地后端使用 fake 引擎。
- **另做过的真实验证**：自带本地后端以 mlx-whisper（whisper-large-v3-turbo）在 macOS 上完成过真实转写请求。
- **尚未系统测试**：真实 B站/YouTube/抖音网站、真实云 STT/LLM 服务、faster-whisper / pyannote 推理、Windows、真实 `tabCapture` 录音链路与长时间（>1 小时）录音。

本项目仅供个人学习与研究使用。请遵守各视频网站的服务条款和当地法律，尊重内容创作者的版权；不要传播录制的音频或据此生成的内容。
