# WatchVid4U · 帮你看视频

[English](README.md) | **简体中文**

收藏夹里攒了一堆视频，想整理成笔记？不想为了几条信息听完一整期播客？或者只是不想把时间花在一个不知道值不值得看的视频上？

WatchVid4U 是一个把视频变成逐字稿和学习笔记的 Chrome 扩展。就像有个 AI 替你看视频，看完还能按你想要的风格整理成笔记。

实现原理：有字幕就直接用字幕（当前仅限b站）；没有字幕时，在视频播放的同时录下标签页的声音再转写。全程不下载视频或音频，所以不会被网站的反下载机制拦截，大多数能播放声音的网页都能用。

## 功能

- **B站字幕优先**（默认开启）：有字幕直接用，没有字幕自动改为录音
- **语音转写**：支持任意 OpenAI 兼容的云端服务，或任意本地 Whisper 服务
- **学习笔记**（可选）：任意 Chat Completions 模型，精简 / 详细 / 纪要三种风格
- **视频画面**（可选）：录制时截图，可让支持图片的笔记模型参考
- **静音录制**：默认录制时不外放声音（录音不受影响），你可以去做别的事；也可以随时打开声音边看边录，看完稍等片刻就能拿到逐字稿
- **播完自动暂停**：视频结束后自动暂停，不会循环重播，也不会自动播放下一条
- **同时录制多个标签页**（默认最多 3 个），转写依次排队
- **本地优先**：材料只保存在浏览器里，只有你授权的服务会收到数据
- **中英文界面**，默认跟随浏览器语言

支持：B站、YouTube、抖音及其他能播放声音的网页。不支持：YouTube Shorts、iframe 内嵌播放器、受 DRM 保护的内容。

## 安装

1. 从 [Releases](https://github.com/lkdlcodyl/WatchVid4U/releases) 下载 `WatchVid4U-<版本>.zip` 并解压。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的目录。
4. 设置页会自动打开。

要求 Chrome / Edge 116 及以上。

## 配置

| 你想要 | 需要配置 |
|---|---|
| B站有字幕的视频 → 逐字稿 | 无需配置 |
| 录音转写 | 设置 →「语音转写」 |
| 学习笔记 | 设置 →「笔记模型」 |
| 让笔记结合画面内容 | 设置 →「视频画面」 |

- **云端转写**：选一个示例（如 Groq）或填写任意 OpenAI 兼容的 `/audio/transcriptions` 地址，粘贴 API Key，点「保存并授权」。
- **本地转写**：选择「本地服务（可选）」，填写地址（如 `http://127.0.0.1:8765`）和模型名，点「测试转写」。可使用[自带后端](local-backend/README.md)或任意兼容的本地服务。
- **界面语言**：在设置页左侧栏顶部的“🌐 中文 / English”切换。

## 使用

从工具栏弹窗、视频页上的浮窗或快捷键开始：

| 操作 | 快捷键 |
|---|---|
| 从当前进度开始 | `Alt+Shift+S` |
| 从头开始 | `Alt+Shift+B` |
| 停止并保存 | `Alt+Shift+E` |
| 显示/隐藏浮窗 | `Alt+Shift+F` |

结果会出现在「材料与笔记」页面，可以阅读、复制、导出和生成笔记。

> 浏览器只允许在你点过工具栏图标或按过快捷键的页面录音。页面提示需要授权时，点一次工具栏图标即可。

## 故障排查

| 现象 | 处理 |
|---|---|
| 提示“需要你授权录音” | 在该页面点工具栏图标，再点「授权并继续录音」。 |
| 提示“服务返回了网页” | 地址多半少了 `/v1`，对照设置中显示的“请求地址”。 |
| HTTP 401/403 | 检查 API Key；本地服务请确认该地址上运行的是你配置的服务。 |
| HTTP 413 | 在「高级」中调低“单次上传上限”。 |
| 附带截图时笔记生成失败 | 模型不支持图片，换用支持图片的模型或关闭发送截图。 |

## 隐私

没有项目方服务器或统计。数据只发给你授权的服务，而且只发送任务所需的内容。详见 [docs/PRIVACY.md](docs/PRIVACY.md)。

## 开发

无需构建，没有运行时依赖。测试需要 Python 3.10+ 和 Google Chrome。

```bash
python3 tests/run_unit.py
```

```bash
python3 tests/run_e2e.py
```

```bash
python3 tests/test_i18n.py
```

```bash
python3 scripts/package.py
```

界面英文译文在 `extension/src/shared/i18n-en.js`，`tests/test_i18n.py` 会报告遗漏的翻译。
